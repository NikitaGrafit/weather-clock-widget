# weather-clock-widget
Виджет рабочего стола: цифровые часы, дата, погода выбранного города со значками, длина светового дня, прогнгоз осадков на сутки, баллы пробок и почасовой ряд. Тонкая настройка вида виджета, изменение шрифта часов из готовых или подгружай свой, формат 24/12 для удобства, язык интерфейса RU или ENG. Возможность обновления виджета..
